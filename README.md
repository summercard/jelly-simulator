# Q弹果冻：重力、球体挤压与复制

打开 `Q弹果冻_重力挤压复制_v003.blend`。当前电脑已安装并启用配套插件。渲染引擎是 Eevee；视口使用实体模式，便于看形变。

## 先这样玩

1. 鼠标移到 3D 视图，按 **N**，打开右侧 **Q弹果冻** 页签。面板较长，向上滚动可以找到复制和抓拉按钮。
2. 点 **开始抓拉互动**，左键按住果冻拖动，松手回弹；快速甩动会带来余晃。**右键或 Esc** 退出抓拉模式。
3. 点 **竖放**，果冻朝向正面镜头，复制体左右并排。切面只随“切面倾角”调整，重力、挤压、摇晃不会移动切面。
4. 点 **球形手指放到当前果冻前**，再点 **按下球体 / 松开**。接触位置会产生凹陷，球体受碰撞阻挡；再次点击撤回并观察恢复。
5. 手动控制球体：在抓拉模式中左键按住灰色球体，拖动改变接触位置；**按住球体时滚轮向上推入，向下撤回**。碰到果冻会受阻，继续向内推会加压并带动果冻晃动。松开鼠标只是停止移动球体，若仍贴着果冻会继续施压；向外撤回或用上述按钮松开。

## 调节手感

| 控件 | 效果 |
|---|---|
| 启用重力下垂 | 开关重力形变 |
| 重力倍率 0–2 | 越大下垂越明显；0 为无重力 |
| 硬度 12–90 | 越小越软、下垂和压痕越明显 |
| 阻尼 0.6–10 | 越小余晃越久，越大越快稳定 |
| 挤压深度 0–0.42 | 自动按压的目标深度；实际压入受硬度与碰撞约束限制，到限后不会穿过去 |
| 切面倾角 0–180° | 平放 0°、正面竖放 90°、倒挂 180° |
| 摇晃力度 0.1–2.5 | 调整来回摇晃的强度 |

可以直接选择 **偏硬 / Q弹 / 软糯** 预设。建议先试 Q弹（硬度30、阻尼2.2），再试软糯（硬度16、阻尼1.7）。

**戳一下、压一下、摇晃** 可快速触发动作；持续来回摇晃可保持摆动。恢复平衡按钮让当前果冻回到当前重力下的平衡形状；不会消除重力造成的下垂。实时模拟开关控制是否持续更新，无需播放时间轴。

## 复制

点面板顶部 **复制一个到旁边**，新果冻出现在右侧，与原件处于相同深度，视口会重新构图。最多6个，数量增加时实时速度取决于电脑性能。

网格和动态状态相互独立：拖动一个不会带动另一个。直接点击果冻会切换当前编号；也可以手动修改“当前果冻编号”。球体归位与动作按钮作用于当前果冻。硬度、阻尼、重力和朝向参数由所有副本共用。不要用普通关联复制替代此按钮。

## 保存与换电脑

使用 Blender 常规保存即可保存场景、副本和参数。重新打开后动态从重力平衡状态开始，点击“开始抓拉互动”重新进入鼠标互动。

换电脑时，在 Blender 4.2 的偏好设置 → 插件 → 从磁盘安装，选择同目录 `kawaii_jelly_interaction.zip` 并启用，再打开 blend 文件。没有配套插件时只能看到静态网格。

此版本是面向实时交互的弹簧形变与球体表面碰撞控制器。当前变形可用 Eevee 渲染，但互动过程尚未烘焙为时间轴动画；直接渲染帧序列不会自动重演鼠标动作。最大形变有稳定性限制。球体防穿透应在实时模拟开启、使用面板抓拉模式时体验。

## 验证记录

本目录保存了数值测试结果：硬度12、30、75、90下的球体大幅推入阻挡、局部凹陷、撤回恢复、切面固定、另一副本不受挤压影响；以及平放/竖放/倒挂的重力、硬软差异和摇晃回弹。防穿透测试中球体始终位于受压表面外侧，固定切面位移为0。
